## 🚀 Featured Engineering Projects

### 🛡️ [SentinelX](https://github.com/Vishwajeet2005/SentinelX) | Enterprise Anti-Cheat Infrastructure
**Architecture:** C++, Go, Apache Kafka, Zero-Allocation Memory

An enterprise-grade anti-cheat telemetry pipeline designed for high-concurrency environments like Unreal Engine and Unity multiplayer titles.
- **Problem:** Existing anti-cheat solutions suffer from high latency and client-side performance degradation during massive telemetry ingestion.
- **Solution:** Engineered a zero-allocation native C++ SDK featuring a lockless ring buffer design, bringing telemetry overhead to `<0.1ms` per tick.
- **Security:** Implemented HMAC-SHA256 signed payloads to ensure telemetry data remains tamper-evident and cryptographically secure in transit.

### 🔮 [AlphaScope](https://github.com/Vishwajeet2005/AlphaScope) | Dual-Signal Intelligence Terminal
**Architecture:** JavaScript, React, Serverless Functions, Groq LLM

A high-conviction market trading intelligence terminal for the Indian stock market.
- **Problem:** Retail traders are overwhelmed by false-positive trading signals and noise in live technical analysis.
- **Solution:** Built a dual-agent fusion engine that cross-validates independent algorithmic signals before executing or recommending a trade, drastically reducing false positives.
- **Features:** Integrates live NSE telemetry with Groq-powered AI agents that generate real-time, easily digestible market briefs.

### 📈 [NSE Trading System](https://github.com/Vishwajeet2005/NSE_Trading) | ML-Powered Trading Terminal
**Architecture:** Python, FastAPI, Scikit-Learn, VADER NLP

A semi-autonomous backend trading terminal built specifically for NSE (National Stock Exchange of India) equities.
- **Problem:** Relying solely on technical indicators fails during high-volatility news events.
- **Solution:** Blended rule-based technical analysis with a massive Random Forest machine learning model trained on 15 years of historical NSE data.
- **AI Integration:** Implemented VADER NLP for real-time sentiment analysis on market news to dynamically adjust risk thresholds before major market movements.

### 🤖 [Claude Code Studios](https://github.com/Vishwajeet2005/Claude-Code-Game-Studios) | Multi-Agent Orchestration
**Architecture:** Shell Scripting, LLM Orchestration

An end-to-end autonomous game development orchestration simulation.
- **Overview:** Coordinated an ecosystem of 48 distinct AI agents, structuring them into a functioning virtual game development studio.
- **Features:** Designed 36 distinct workflow pipelines mimicking real studio hierarchies (Art Direction, System Design, QA, Production), allowing agents to hand off tasks programmatically with zero human-in-the-loop required after initialization.
